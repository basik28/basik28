### 2. BARIS AI — Local PDF Document Assistant

A local retrieval-augmented generation (RAG) prototype for asking questions about user-provided PDF documents.

**What it demonstrates**
- PDF upload and text extraction
- Text chunking and local embedding generation
- Vector storage and retrieval with ChromaDB
- Answer generation using a locally running Qwen model
- Returning source filenames and page references

**Technology:** Python · FastAPI · Ollama · Qwen · ChromaDB · pypdf

**Current limitations:** The prototype is intended for local experimentation. It does not currently provide authentication or per-user document isolation; scanned PDFs are not OCR-processed. It should not be exposed publicly or used with sensitive documents without further security work.

### 3. ZE-HA Kombi — E-commerce Web Project

A product-focused e-commerce web application project developed to explore modern frontend development and backend service integration.

**Technology:** Next.js · React · TypeScript · Supabase · Google GenAI SDK · Tailwind CSS

**Focus areas:** Application structure, responsive interfaces, database integration, and AI-assisted functionality.

**Status:** Development project. Authentication, database access policies, payment flows, environment configuration, and deployment require verification before production use.

### 4. Python Career Tracker

A beginner-level Python command-line application that estimates weekly study time and displays a simple six-day learning schedule.

**What it demonstrates**
- Functions, loops, and conditional logic
- Console input and output
- Basic calculations and structured program flow

**Technology:** Python 3

**Current limitations:** Progress is not persisted between runs; input validation and automated tests are not implemented yet. This project is intentionally presented as a learning-stage application.
